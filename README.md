# PR. 1 – Fundamental Booster (Microsoft Excel)

## Project Overview
This project is based on Microsoft Excel fundamentals and practical formula applications. It contains three worksheets: Student Data, Sales Data, and Employee Data.

The main purpose of this project is to understand and practice Excel formulas, functions, data formatting, and data analysis using sample datasets.

## Worksheets Included

### 1. Student Data
This worksheet contains student IDs, names, subject marks, and enrollment dates.

**Tasks Performed:**
- Applied IF and Nested IF formulas to classify student grades.
- Used AND and OR functions to check student performance.
- Used COUNTIFS to count students based on marks.
- Applied AVERAGEIFS to calculate average scores.
- Used FILTER to extract students scoring above 80.
- Applied TEXT functions such as LEFT, FIND, UPPER, and LOWER.
- Formatted enrollment dates.

### 2. Sales Data
This worksheet contains sales IDs, product names, regions, salesperson names, sales amounts, and sales dates.

**Tasks Performed:**
- Used SUMIFS to calculate sales for specific regions and products.
- Applied COUNTIFS to count sales records.
- Used VLOOKUP to retrieve product details.
- Applied INDEX and MATCH to find sales amounts.
- Used XMATCH to find product positions.
- Practiced INDIRECT and OFFSET for dynamic cell references.
- Applied ROUND, CEILING, and FLOOR functions.
- Calculated date differences using TODAY.

### 3. Employee Data
This worksheet contains employee IDs, names, departments, salaries, and joining dates.

**Tasks Performed:**
- Used XLOOKUP to find employee salaries.
- Applied VLOOKUP to retrieve employee names.
- Used INDEX and MATCH to find department details.
- Applied COUNTIFS to count employees by department.
- Used AVERAGEIFS to calculate average salaries.
- Applied IF formulas to classify salary categories.
- Used DATEDIF to calculate years of service.
- Applied UPPER and FILTER functions.
